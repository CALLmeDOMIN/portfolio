Keeps a stocktake of what is actually in my fridge. Receipts get imported as
JSON instead of typed in by hand, and it builds a shopping list from what has
run out, with a tick-off flow for using it in a shop.

The receipt import is what makes it worth having. Manual entry is where every
other fridge app loses me.
